# Changelog

All notable changes to this project are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-11-22

### Added

- EXIF stripping and optional max dimension on generated copies
- Anonymous request cache with publish/comment invalidation
- Spam and trash sweep on a configurable schedule
- Open Graph and Twitter cards with image fallback
- Consent-gated benchmark with downloadable request snapshot
- REST purge route behind capability checks
- Site health tests for cache, encoders, cron and database
- Referrer tracking with a capped log
- Async image decoding with fetch priority on the hero image

### Notes

- First public release. No upgrade notes yet.
